# 🍽️ DineFlow – Restaurant Management System

DineFlow is a full-stack web-based Restaurant Management System designed to simplify and streamline restaurant operations. It provides an integrated platform for managing food menus, customer orders, kitchen operations, restaurant tables, billing, and business reports.

The application features a responsive React.js frontend and a secure Java Spring Boot backend, with PostgreSQL for database management.

### 🚀 Key Features

- **Admin Authentication:** Secure login and role-based access using Spring Security and JWT.
- **Menu Management:** Add, update, delete, and manage food categories and dishes.
- **Customer Ordering:** Browse menus, add food items to the cart, and place orders.
- **Kitchen Management:** View incoming orders and update food preparation statuses.
- **Order Tracking:** Track order progress and status updates.
- **Table Management:** Manage restaurant tables and their availability.
- **Billing System:** Generate bills and manage payment statuses.
- **QR Code Generation:** Generate QR codes for restaurant operations.
- **Reports & Analytics:** View restaurant sales and operational reports.
